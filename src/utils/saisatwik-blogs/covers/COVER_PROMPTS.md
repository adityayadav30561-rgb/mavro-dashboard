# SaiSatwik Blog Cover Prompts (ChatGPT image generation)

**Size:** 1536 x 1024 px (3:2 landscape), the same ratio as existing covers. WordPress and AIOSEO crop the social preview to 1200x630, so keep important text away from the top and bottom 10%.
**Format:** PNG or JPG, under 1 MB if possible.
**Filename:** save each image as `src/utils/saisatwik-blogs/covers/<slug>.png`, using the slug shown in each heading. Alternatively, send the images in chat in this order and I will name them.
**Upload:** `npm run create:saisatwik-blog -- <slug> --cover-only` uploads the image, sets alt text and makes it the featured image. Content and dates are not touched.

**Shared style (paste once at the top of every ChatGPT chat, or prepend to each prompt):**

> Create a landscape blog cover image, exactly **1536 x 1024 px** (3:2), for a B2B SAP consulting company. Style: clean corporate infographic poster, white-to-light-blue background, deep navy (#0B2A5B) and SAP blue (#0A6ED1) palette with one accent colour named per prompt. Big bold sans-serif headline top-left (Inter/Montserrat style), two lines max, with the key phrase in SAP blue. A photoreal or 3D-rendered hero visual on the right half. Below the headline: a short subtitle line, then a row of 4 to 6 rounded icon cards, each with a simple line icon and a 2 to 4 word label. Thin navy footer strip with one summary sentence. Generous whitespace, crisp text, no spelling errors, no lorem ipsum, no fake logos, no watermark. Do not draw the SAP logo; write "SAP" only as plain text inside the headline. Text must be fully legible at 800 px wide.
